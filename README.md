# Build LLM From Scratch

A small GPT-style language model built with Python and TensorFlow, including training, evaluation, inference, guardrails, and an API.

## Setup

```bash
pip install -r requirements.txt
```

## Train

```bash
python train.py
```

## Generate text

```bash
python generate.py
```

## Run the API

```bash
python api.py
```

Model checkpoints are kept locally and are not committed to Git.
